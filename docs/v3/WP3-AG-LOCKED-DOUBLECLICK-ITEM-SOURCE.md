# v3 工作目录：列锁定 / 文件后缀 / 双击导航 / 加载保护 / 单项源码详情（2026-10-08）

## 功能契约

**AG 列锁定。** 不允许拖动改变表格列顺序或用拖拽更改列宽（`suppressMovableColumns`、`suppressMovable`、`resizable:false`）。原有列值 All/多选过滤、排序和表格与源码窗分割条仍保留。

**类型列。** 目录显示 `目录`；非目录按末尾文件扩展名显示小写带点后缀，如 `.md`、`.pdf`、`.json`；无扩展名为 `无后缀`。改动同步进入类型列枚举 All 筛选和源码中的选中行「类型」字段。不改物理文件名。

**单击/双击。** 单击目录或文件的任意可见行仅选中该项目，在右侧只读源码窗展示这个项目的名称、真实 Mac Vault 路径、类型、字节数（文件）、修改时间、版本及 inode。双击**目录名**才导航进目录；非名称列双击不会导航，文件双击不导航。为 iPad Safari 触屏提供 650ms 内对同一目录名连续两次点击的双击兼容路径。首行「返回上级目录」仍单击返回。

**加载中锁定。** 开始切换子目录时立即在 AG 表上显示「正在加载目录…」及进度转圈，`aria-busy=true`，AG 表 `inert`；防止重复点击或选择。文件操作区同步 `inert`，避免旧目录下意外创建文件。无论正常结束还是请求失败，都必须在 `finally` 恢复可用，并保留错误状态提示。首次读取目录不更改真实库；没有额外预加载完整目录树。

**右侧只有单项详情。** 未选中时源码窗显示简短引导，不显示整个目录的内容清单、聚合统计或 `内容:[...]`。单击一个目录，源码窗只显示这个**目录项本身**的 JSON 详情；进入目录成功后保留这个目录项详情。单击文本文件，源码窗在同一个 CodeMirror 中显示选中行详细信息，随后显示真实文本的有界只读预览（最多 256KiB）。PDF/图片显示单项详情，不解码二进制。保存功能仍禁止覆盖现有文件。

## UIC 回归验收

1. **列固定**：启动工作目录，向其他列拖动「类型」表头，结果列序不变；修改列设置后仍不可拖动。自动：临时真实磁盘 Chrome E2E。
2. **类型后缀**：`notes.MD` → `.md`，`binary.pdf` → `.pdf`，`root-note.txt` → `.txt`，`extensionless` → `无后缀`，目录 → `目录`。类型列 All 枚举与源码详情一致。自动：临时真实磁盘 Chrome E2E。
3. **单击目录**：当前路径不变，右侧源码为被选中目录本身的 JSON 元数据，无聚合目录内容。自动：临时真实磁盘 Chrome E2E。
4. **双击子目录/触屏双击**：2 次点击同一目录名进入；测试阶段人为增加网络延时，加载遮罩必须显示，AG 和文件操作区不可用，完成后恢复；上级返回仍可用。自动：临时真实磁盘 Chrome E2E；iPad Safari 物理行为待用户审核。
5. **文件与非文本**：单击真实 Markdown 行预览详细信息及有界正文；点击 PDF 行只显示文件详情；源文件字节未修改。自动：临时真实磁盘 Chrome E2E。
6. **公网只读**：模拟 iPad/iPhone 屏宽，单击目录不跳转，再双击才进入；读到 Mac Vault 的真实验证 Markdown；不发生新的写入。自动：公网 Chrome Touch 模拟；物理 iPad Safari 标记 `manual-external`。
