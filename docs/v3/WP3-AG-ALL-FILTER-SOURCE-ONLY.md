# v3 工作目录 AG 列值筛选（All）和单一源码窗 · 2026-10-08

## 当前功能契约（工作目录）

- 操作：点击 AG Grid 任一列标题的筛选入口。
- 需要：筛选弹窗列出该列当前已加载目录条目中的**实际列值**，第一项为 **All**，下面是可多选的枚举值；由 v2 `EnumCheckboxFilter` 通用组件提供，不引入 AG Grid Enterprise。
- 效果：默认 All，勾选特定值仅显示匹配数据；再次勾选 All 恢复全部当前已加载数据。受过滤影响的仅为 AG 主体行，固定顶行「↩ 返回上级目录」不会消失。名称、类型、大小、修改时间、版本列均支持（隐藏列遵从设置）。切换目录时清除筛选，避免上个目录枚举条件污染新的文件列表。
- 取消：顶部独立 `directory-search` 名称搜索框和 quickFilterText；目录筛选入口统一在 AG Grid 的列菜单中。

## 右侧源码窗（真实 Mac Obsidian 根）

- 仅保留复用 v2 `WorkingEditor` 的 CodeMirror 容器，移除独立的「源码」标题栏、选中项标题、元信息列表和提示区；右窗可见内容全部在源码内。
- 单击 AG Grid 文件行：源码窗显示「选中行详细信息（非原文件内容）」的结构化记录（名称、路径、类型、大小、修改时间、版本、节点 ID）。若为文本文件，同窗接着显示「原始文件源码（只读）」及前 256KiB 文本。源文件本身不会被附加任何详细信息或修改。
- 单击目录行：保持进入该目录；右窗显示该目录行的元信息、当前页子项目清单；返回上级后显示所在目录概况。
- PDF、图片、二进制文件：只显示详细信息和非文本提示，不做错误的 UTF-8 预览。
- 其他边界不变：单次有限范围读、CAS 版本保护、文件查看只读、隐藏 `.obsidian` 不可访问、公网 iPad 经 Mac 同一授权 API。

## UI Interaction Contract / 验收

1. 初始：Mac/iPad Safari 打开 v3，经授权获得真实 Root，AG Grid 默认 All，右源码窗显示目录详情；没有独立名称输入框，右窗没有元信息外置面板。副作用：仅文件元数据 GET。
2. 列筛选：点击「类型」列过滤按钮，All 初始选中 → 取消 All、选择「文件」，AG 主体只显示文件，固定顶行不隐藏 → 勾回 All，文件与目录均恢复。副作用：只改变页面过滤模型，没有后台写入。自动：临时真实磁盘 Chrome。
3. 进入目录：在清除列过滤后点击目录行，AG 列出子目录，源码窗显示目录行详情和该层目录清单；首行返回上级仍在。副作用：仅目录读取。自动：临时真实磁盘 Chrome。
4. 文件：点击 Markdown，源码窗同一 CodeMirror 内出现元数据和真实文件源码；对 >256KiB 文件必须显示截断提示，不能加载全文件。副作用：仅有界读取。自动：临时真实磁盘 Chrome。
5. PDF：点击二进制文件，源码窗显示类型/大小/路径/版本元信息，但不包含二进制正文。自动：临时真实磁盘 Chrome。
6. 外网：iPad/iPhone 尺寸 Chrome 经公网只读验证真实 Mac Obsidian 里的测试 Markdown；用户实体 iPad Safari 触控和 iCloud 同步仍需人工验收（manual-external）。

注意：设置 tag 继续复用 v2 的 `TableConfigurationGrid` 和 CodeMirror JSON 通用组件。v2 的旧配置表仍通过同一个可泛型 `EnumCheckboxFilter` 调用，原有 `setConfig` 和数据协议不变。
