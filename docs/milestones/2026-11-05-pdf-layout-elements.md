## 共用约束

- **CM6 编辑器中的 Markdown 是唯一可编辑源码**；CMD 管理标签／注释读写，AG 只是筛选投影，不持有第二份源码。
- PDF 和原始 MinerU JSON 是只读证据；文档修正不能静默篡改原始坐标或封存来源。
- 行注释和 `lb` 是审阅决定，**导出干净 Markdown 时才执行实际断行合并**。
- AG 审阅下拉应原位更新，不能因改值而重建全表或丢失筛选、定位、滚动。
- 块与 OCR 原始块的物理身份在重新归入／排序后必须继续可追溯。
