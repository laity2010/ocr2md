# WP29C · 裸图片 URL 定位与渲染

基线：8483614（WP29B）。实机截图中四个已下载图表错误归为未引用文件。只读核对实际 Buffett 样本 SQLite：11 张图片中七张为 Markdown 图片语法，四个 chart_body 是独立裸 CDN URL：111/p4b1s2、116/p5b0s2、252/p12b8s3、258/p13b1s4；对应文件名哈希均匹配。

V2 新增共享裸图片行解析，限已允许的 MinerU HTTPS 图片 URL 或已批准 media/ 本地图片路径；不扫描代码围栏、HTML 注释、正文内的普通链接或四空格缩进。媒体投影仍用原 findLabMedia、公共 MD Line、媒体状态与同一 CM6 原生事务；Markdown-it 仅 V2 启用独立图像 block token，准确保留单行映射，复用 WP29B 本地文件解析。不增加表、改布局或批量改写原文。

验收：使用原书数据库只读 backup 至临时目录并复制 11 个本地图片文件；隔离测试的 PDF.js 使用生成的同页尺寸 PDF 夹具，实际逻辑覆盖框和 PBS 来自原数据库。阻断 CDN，Chromium 与 WebKit 均实际验证全部 11 项的行号、PBS、已下载状态，四张遗漏图的 AG 点击→CM6、PDF 高亮、Markdown 图片自然宽度；批量采用只产生一次 11 块旧值 CAS 保存，原文精确比对、撤销、重做及重开仍保持 11 项定位。原书零写入。Python 媒体 API 测试通过。
