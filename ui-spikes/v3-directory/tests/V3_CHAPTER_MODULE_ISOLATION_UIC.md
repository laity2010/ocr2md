# FC-V3-CHAPTER-MODULE-ISOLATION-001 / UIC-V3-CHAPTER-MODULE-ISOLATION-001

## 目标
- 章节定界、章节标题、章节媒体、章节表格、章节 LaTeX 五个业务模块各有**唯一入口代码文件**，统一注册，工作台只负责调度。
- 本轮“搬家”严禁改变识别结果、按钮、AG 列、DIRjson/章节文件保存协议、PDF 对照、撤销重做或云盘路径。复用现有 IR 服务、扫描器和 V2 组件；不复制另一套编辑器。

## 操作 / 需要 / 效果
- 需要：原文 PDF、OCR/已保存 DIRjson、已发布章节，拥有授权的 Mac Vault；非已发布章节不得写入。
- 操作：从根目录进入章节定界；发布后从章节下拉进入章节清洗；切换标题、媒体、表格、LaTeX；媒体触发下载并观察状态。
- 效果：显示、排序、三窗定位、下载错误报告、状态栏、按钮逻辑与 bo 版等价；模块切换不会写入 Vault。真实交互仍通过相同的产品界面，模块文件是实现重组而非另设调试入口。
- 模块契约：每个独立文件导出一个 ModuleDefinition，声明 id、stage、AG 行扫描（清洗模块）、模块工具 ID；媒体文件负责下载任务状态与批处理，定界负责章节目录枚举及其阶段定义，标题负责标题序号工具，表格/LaTeX 各有扫描入口。registry 维护唯一稳定注册表与类型检查。
- 界面：顶栏导航仍用于根目录与章节切换；AG 左顶栏仍用原生 select，切换仅显示对应工具；上栏显示任务进度、AG 媒体列显示逐项原因。
- 不变量：没有用户明确点击时不发起图片 POST；扫描纯函数不读写文件；错误任务不能吞掉报告；保持源 MD 和 PDF 锚点；不触碰正式书籍或现有 WIP。
- 验收：scan/catalog/heading core 测试；既有 Chrome/WebKit 模块切换、媒体成功/失败、导航与定界回归。通过新 registry 的核心测试断言模块唯一性、各模块扫描结果保持一致。
- 留待下一轮：V3 和 V2 共有的 AG 列表配置、IR Workbench 内章节定界细节、公共 PDF 定位；只有确定为“热点”才再拆，不在本轮借机重构。
- 人工审核：待用户在 iPad Safari 验收。
