# FC-V3-ONE-TEMPLATE-001 / UIC-V3-ONE-TEMPLATE-001

## 全项目工作台模板：根据业务装载预览

**统一组件：** V3 各 Tag 复用工作台的版本、唯一状态、顶部四个全局操作槽、目录导航、AG Grid、CodeMirror 源码、AG↔源码选择定位、CSS/字体/iOS 原生光标、AG/源码可拖动分隔条和窄屏上下自适应。所有业务差异只由场景状态与已暴露的展示参数驱动。

**明确例外（2026-10-11，用户要求）：** 工作目录和设置 **没有预览窗**，采用 AG＋源码两个窗格；源码占满整个右侧区域，不渲染 MD/PDF Tab、预览占位内容，也不渲染源码/预览横向分隔条。工作台保留 AG＋源码＋预览三个窗格及双分隔条。禁止恢复不必要的“禁用预览”占位窗。

**工作目录：** 左 AG 选择文件/目录、双击进入；右 CodeMirror 只读详情/文件源码，底部折叠的文件操作附着于源码窗，不创建第三窗。表格不可编辑，选择→源码联动；目录加载期间禁用表与操作。

**设置：** 左 AG 负责配置分类、筛选与选中定位，右 V2 CodeMirror JSON 是唯一配置源。Mac Vault 授权放在 AG＋源码模板外、同一设置页中的独立可折叠区域，允许首次授权且不侵占右源码高度。布尔 AG 勾选与 JSON 双向联动；保存前只修改配置草稿；错误 JSON 禁止写入偏好。设置页不保留任何独立预览窗。

**工作台：** 章节定界、章节清洗、IR、原 PDF/MD 预览/定位、源码修改和保存不变。工作台的 Preview 和原 PDF.js 后台加载仍保持；不受另两 Tag 的双窗例外影响。

**验收步骤／自动化：** `chapterPublishBrowser.cjs` 在所有 Tag 检查共用外壳、统一按钮槽、AG＋源码、纵向 AG/源码分隔条；只在工作台检查 Preview 与横向分隔条；另外检查目录/设置源码占满右窗高度、授权与文件操作没有消失。`macVaultHttpSmoke.cjs` 覆盖真实授权、AG 选择、只读源码和文件操作，`irWorkbenchBrowser.cjs` 回归 IR、PDF.js、保存，`settingsSmoke.cjs` 回归配置。Chromium、WebKit 分别验收。iPad Safari 分隔条/光标真机审核状态：待用户审核。

**不变量：** 不修改用户真实书籍或原 PDF/OCR JSON；不能把只读目录源码变为可编辑；不允许重复的导航或独立样式分叉；没有预览功能时不能空占空间；存储密钥与 JSON 偏好隔离。业务保存权限不属于展示设置。


**中央设置组件接入：** 设置 Tag 首列；内部左右 AG／CodeMirror 由 Agent Link Shared Settings 的 `layout="horizontal"` 执行，顶部全局状态/按钮仍归 OCR2MD 模板。场景高度/宽度共享模板约束，Mac Vault 作为设置页的独立兄弟区域运行（不在共享组件内部）；旧设置页 AG/源码被移除。
