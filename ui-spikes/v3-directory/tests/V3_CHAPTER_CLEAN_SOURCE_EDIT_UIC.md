# FC-V3-CLEAN-EDIT-001 / UIC-V3-CLEAN-EDIT-001

- 功能：章节清洗源码窗增删改（共用 V2 CodeMirror，不另开编辑框）
- 操作：在章节清洗 → 章节标题模式，直接点击源码窗输入、选区替换、删除文本/标题、补录 `#` 标题，；AG 标题仅用于只读定位，不进入源码编辑状态；使用撤销/重做和保存章节。
- 需要：Mac Vault 已授权；导航位于 `chapters/` 下已发布、可写入清单的 Markdown 文件；来源未被外部修改。
- 初始状态：加载中的章节禁止编辑；读取并校验完整章节后，源码 contenteditable 启用；撤销/重做/保存默认禁用。
- 预期界面：增删改立刻同步源码、AG 行（按实际 `#` 层级）和 Markdown 预览。删除标题时不得由 IR/OCR 旧建议自动补回。AG 点击标题只定位源码位置与预览，不抢夺键盘焦点、更不能进入 AG 单元格编辑；用户直接点击源码文本才开始编辑。编辑不应跳回首行，失焦不丢弃选区。
- 撤销/重做：按钮和 CodeMirror 内 ⌘/Ctrl+Z、⌘/Ctrl+Shift+Z 操作同一份章节历史；撤销后输入新文本应清除旧重做分支。
- 保存：点击保存章节时进入只读 CAS 写入；服务器核实发布清单、文件原有版本并原子替换，随后校验 SHA-256 与文件 revision；保存成功解除锁定、清除 dirty。失败保留待保存文本和历史，禁止悄悄覆盖外部修改。
- 副作用：仅按用户明确按下保存按钮才写目标章节 MD。浏览/编辑中不改 PDF、OCR JSON、DIRjson 以及其他章节。导航离开有未保存修改时要求确认。
- 不变量：同一章节实际存在的 Markdown 原文是唯一编辑真源；AG 仅只读导航，点击不触发写入、聚焦编辑器或单元格编辑；AG 扫描不反写源码；未授权或其他模式的文件不可写；页面异步加载未完成不能用旧 DOM 输入；保存不能以按钮暂时禁用视为已经成功。
- 自动化：browser；在隔离 Vault 中执行真正发布 → AG 点击只定位 → 直接在源码窗选区修改标题 → AG/预览更新 → 撤销重做 → 新增标题 → 删除标题 → 撤销 → CAS 保存 → 重入确认 → 拒绝重新覆盖人工清洗。
- 证据：`tests/chapterPublishBrowser.cjs`（Chromium + WebKit）；`tests/chapterHierarchyBrowser.cjs`（仅浏览不写盘）；`src/workbench.ts` 保存锁及扫描联动。
- 人工审核：待用户审核，尤其 iPad Safari 中文输入法与行内长按选区。
