# FC-V3-CLEAN-MODULE-TOOLBAR-001 / UIC-V3-CLEAN-MODULE-TOOLBAR-001

- 功能：章节清洗模块及模块工具固定于 AG 表顶栏。
- 操作：通过工作台章节目录进入 `chapters/*.md`；点击 AG 表左上“章节清洗 · 当前模块 ▾”，依次选择“章节标题”“媒体”“表格”“LaTeX”。
- 需要：当前书籍已发布章节、Mac Vault 可读取章节；模块扫描只能读取当前 Markdown 源码，不能触发写入。
- 初始状态：章节清洗默认“章节标题”，AG 顶栏下拉位于该顶栏所有操作之前；“标题序号”默认勾选并只在标题模块出现；“规范化 Obsidian MD”按钮不存在。
- 预期界面：切换后下拉立即显示选中模块，AG 表只显示对应类型的条目：标题、图片与来源、HTML 表格、行内/独立/表格内公式；“媒体”只显示图片而非表格；“表格”只显示 HTML 表格而非图片。标题仅显示标题序号开关，媒体仅显示图片下载工具，表格及 LaTeX 目前无专用工具时不显示多余按钮。切换模块不改变章节导航、源码/预览窗状态。
- 数据副作用：模块切换及扫描均无文件或网络写入；标题序号仅影响 AG 显示；下载图片仍要求显式点击且符合原保存与 CAS 条件。
- 不变量：标题/图片/表格/LaTeX 共同遵守 AG 只读定位、源码窗编辑、预览及 PDF 来源对应规则；保存、撤销、重做继续在顶栏全局操作区。旧章节的规范化转换内核保留，但不再提供单独的用户可见按钮，新发布的章节直接采用 Obsidian 格式。
- 自动化：browser（Chromium / WebKit）；用临时 Vault 测试不同模块行数、工具显隐、左侧位置与零写入；core 测试扫描分组。
- 证据：`tests/chapterHierarchyBrowser.cjs`、`src/chapterElementCatalog.test.ts`。
- 人工审核：待用户审核，特别是 iPad Safari AG 顶栏触摸下拉位置。

## 2026-10-12 iPad Safari 实机退回与修正门禁

- 退回证据：iPad Safari 的四项自绘弹出菜单只显示四个空白按钮轮廓，无法辨认模块；进入“媒体”后仍露出仅属于章节定界的“只看一级标题”和“起始序号”。
- 初始状态：已打开 `chapters/*.md`，AG 左上显示原生 `select`“章节清洗 · 章节标题”；无需自绘绝对定位弹层，点选后 Safari 自带选择器必须列出有名称的四项。iPad 及桌面均须有可访问的选项文本。
- 动作 / 预期：选择“媒体”后，菜单值、AG 行及“下载图片”同步更新；“只看一级标题”“起始序号”“标题序号”全部实际不可见。切换表格/LaTeX 也隐藏这些标题工具；回到章节标题只恢复“标题序号”。返回书籍根目录时，章节定界专用工具恢复，不被清洗隐藏规则污染。
- 不变量：切换不会改源码、DIRjson、PDF、已发布章节及工具栏的撤销/重做/保存/发布；允许临时 Vault 内的静态预览读操作，不触发写入。
- 自动化：WebKit 模拟 iPad 1024×768 触控 + Chromium，要求原生 `select` 选项有真实文本且显示状态正确，切换后以 `getComputedStyle` 与 `isVisible` 确认全部非本模块工具被隐藏；真机 Safari 再由用户审核。
- 2026-10-12 二次修正：面板以 `data-work-mode=cleaning` 隔离章节定界专属三个工具（OCR 来源、只看一级标题、起始序号），即使异步 IR 组件把 `hidden` 再置为 `false` 也不得露出；下拉选择器使用 `color-scheme:dark` 和系统 `CanvasText/Canvas` 保持原生选项对比度。自动化模拟“后台 IR 重新显示按钮”竞争条件并检查实际计算样式；Safari 原生 OS 选择器仍须真机复核。
