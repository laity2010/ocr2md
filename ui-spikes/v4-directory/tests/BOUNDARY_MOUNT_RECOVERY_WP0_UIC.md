## 直接故障链与证据边界

- `show()` 在 try/catch 外创建 resident、工具栏和 TriPane。布局构造失败后，resident 和搬出的工具栏节点未回收，`live` 仍为空。
- 下一次进入重新创建 resident；旧视图和新视图含同名 ID。遗留控制器通过全局 ID 找到停在屏幕外的第一份控件，将 224 块数据恢复到隐藏实例。第二份可见视图为空，但状态栏仍报告恢复成功。
- `workspace.selected` 在更新 `selectedBook` 前刷新导航；若已经进入过空工作台，常驻实例重入跳过初始化，导航一直为空。
- 用首次 `#boundary-layout` 的定位上下文检查返回 static 注入实际构造器异常，随后只执行真实 UI 操作，复现与用户截图相同的空白三窗、重复 H1 工具、空导航、成功状态。**这是失败恢复链的确定复现；没有捕获用户 iPad 首次异常堆栈，不能断言其首次异常必然由 CSS 时序引起。**
